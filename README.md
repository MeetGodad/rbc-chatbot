# RBC AI Assistant

Welcome to the RBC AI Assistant project! This repository contains the code and resources for an AI-powered chatbot designed to assist with various tasks related to RBC (Royal Bank of Canada).


## 🚀 Project Overview

The RBC AI Assistant is a conversational AI application that helps users interact with RBC services more efficiently. It leverages natural language processing to understand and respond to user queries, providing a seamless banking experience.

### Features

- **Natural Language Understanding**: Uses advanced NLP techniques to comprehend user input.
- **Task Automation**: Automates common banking tasks such as checking account balances, recent transactions, and more.
- **User-Friendly Interface**: Provides an intuitive interface for easy interaction.
- **Scalable Architecture**: Built to handle a growing number of users and queries.

## 🛠️ Technologies Used

This project utilizes the following technologies:

- **React**: For building the user interface.
- **Next.js**: For server-side rendering and building static websites.
- **Tailwind CSS**: For styling the application with a utility-first CSS framework.
- **OpenAI Assistance API**: For implementing AI-driven responses and interactions.

## 🛠️ Installation

Follow these steps to set up the RBC AI Assistant on your local machine:

1. **Clone the Repository**

   ```bash
   git clone https://github.com/MeetGodad/rbc-chatbot.git
   cd rbc-chatbot

Install Dependencies
Ensure you have Node.js and Python installed, then run:
bash
npm install
pip install -r requirements.txt

Run the Application
Start the development server:
bash
npm run dev

Access the Chatbot
Open your browser and navigate to http://localhost:3000 to start interacting with the AI assistant.
## 📚 Usage
Interacting with the Bot: Simply type your queries into the chat interface and receive instant responses.
Supported Queries: Ask about account details, recent transactions, and more.
